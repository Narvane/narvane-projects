# Is Defined

## Purpose

This checker verifies whether each project satisfies the **definition of being defined**.

---

## Execution Instruction

> **Check if each project meets all definitions declared in `definition_of_defined/`.**

1. Navigate to `definition_of_defined/`
2. Read all definition files (e.g., `Follow Principles`, `Each Project Has Description`)
3. Navigate to `defined_projects/`
4. For each project:

   * Evaluate whether it satisfies all definitions

> **`by_pass_definition_principles.md` does not replace a project description.** It only records principle exceptions; the “each project has description” definition still requires a dedicated `.md` at the project root as specified in `definition_of_defined/each_project_have_description.md`.

---

## Output Format

For each project, provide:

* Status:

  * ✅ Defined
  * ❌ Not Defined

* Short justification indicating:

  * If it follows principles
  * If it has a description

---

## Final Note

> **A project is defined only when it satisfies all required definitions.**
